
# MNIST Neural Network

Ye ek neural network project hai jo handwritten digits (0 se 9) pehchanta hai.

## Result
- Train accuracy: lagbhag 99.5%
- Test accuracy: lagbhag 98%

## Tools
- Python
- TensorFlow / Keras
- Google Colab

## Model
- Input: 28x28 image
- Hidden layer: 128 neurons (ReLU)
- Output layer: 10 neurons (Softmax)
- Optimizer: Adam, 10 epochs

## Kaise chalayein
Notebook `MNIST_Neural_Network.ipynb` ko Google Colab me kholo aur saare cells run karo.
